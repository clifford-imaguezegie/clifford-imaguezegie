## Featured projects

### [TEAD AI — Agentic Telecom Network Investigation & RCA Platform](https://github.com/clifford-imaguezegie/telecom-ai-engineering-demo)

Independent applied engineering project investigating AI-assisted 5G network assurance. Integrates **ML-assisted fault localisation, LangGraph-orchestrated specialist analysis, structured network telemetry and knowledge-grounded RCA**. Nine recorded investigations use **synthetic-network scenarios**, with reported network assessment/localisation times of **15.0–24.3 seconds** and end-to-end incident investigation times of **2m 48s–4m 33s**. An experimental evidence-representation change reduced the **SP08 evidence payload by 98.7%**.

The Streamlit showcase presents **recorded execution replays**, evidence and engineering metrics. It does **not** perform live network remediation or new model inference within the public demonstration.

### [Telecom AI Knowledge Orchestration](https://github.com/clifford-imaguezegie/telecom-ai-knowledge-orchestration-demo)

A telecom question-answering demonstration comparing **LLM-only reasoning, strict knowledge grounding and augmented retrieval**. Uses **RAG, MCP knowledge access, FAISS, BGE-M3 embeddings, model routing and provenance-aware responses** to explore when retrieval improves—or degrades—technical answer quality. The project documents containerised deployment on **Google Cloud Run**, including operational considerations such as memory usage, startup latency and inference cost.
